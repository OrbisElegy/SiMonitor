# 逐搏充盈与房室时序

原加速自主心律每搏沿用参考射血量，室速/室上速仅按固定 RR 折减，
缺少房室相位影响。
血压仍由血管储库和压力轮廓生成，不设目标值，也不按报警线裁剪。

## 依据和模型假设

[Maloney 等，1992](https://pubmed.ncbi.nlm.nih.gov/1595536/)在诱发室速中观察到
房室同步与每搏量的关系。[Toeda 等，1985](https://pubmed.ncbi.nlm.nih.gov/4032740/)
支持适当的先房后室收缩有利于射血，贡献随心功能而异。这些研究支持机制方向，
不验证本项目的固定参数或绝对压力。

`CardiacFillingPerfusionIllustration@2` 使用作者选定的饱和充盈曲线：

```text
r  = min(实际机械 RR, 800 ms)
d  = max(0, r − N)
d₀ = 800 ms − N
g  = [d / (d + 200 ms)] / [d₀ / (d₀ + 200 ms)]
     × [0.75 + 0.25 × a / 120 ms]
```

`N` 为有效不可充盈时间，普通心律 300 ms，SVT、种子心率和房扑 2:1–4:1
为 240 ms，固定 1:1 房扑为 160 ms。它们概括收缩与早期舒张恢复，不能解释
为从 QT 推导的瓣膜开放时间。`a` 为心房收缩与晚期充盈窗的有效重叠，普通
心房支持 120 ms，封顶 120 ms。房颤取零；房扑另用缩短、减弱的机械贡献。

`1000g` 以银行家舍入一次取整数千分比。长间歇最多恢复参考每搏量，
不重复累加多个心房收缩来产生无界射血。第一搏采用名义 RR/已声明的循环
间期和独立压力初值，不生成起点之前的心房收缩。机械漏搏、间歇恢复、
文氏型延迟和 VT 夺获按上一实际接受事件计时；被阻滞的 P 不生成机械射血。

| 默认预设 | RR | 每搏系数 |
| --- | --- | --- |
| AAR | 600 ms | 840‰ |
| AJR | 600 ms | 630–840‰ |
| AIVR | 750 ms | 727–969‰ |
| VT | 375 ms | 286–346‰ |
| VT 夺获/随后一搏 | 330/420 ms | 137/394‰ |
| SVT | 300 ms | 235‰ |
| 固定房扑 1:1 / 2:1 / 3:1 / 4:1 | 200/400/600/800 ms | 175/513/742/850‰ |
| 完全性房室阻滞的两个逸搏示例 | 1200/2000 ms | 默认相位交替 1000/750‰ |

足够慢、房室时序合适的窦律/房性逸搏保持 1000‰；慢心率本身通过减少
射血次数影响灌注。心房/心室独立时，相同 RR 可因相位不同得到不同强度。
融合、双向、扭转等 ECG 形态不会单独增加机械事件。

## 通道处理与确定性

同一每搏系数作用于原始 RQ 输入、压力脉动高度与光学幅度。
变化强度的压力轮廓以加法替换当前搏动的参考 RC 起伏，保留历史储库回流；
不能将已经减弱的储库再乘一次减弱脉搏而造成近似平方折减。
普通参考节律保留既有启动轮廓；相同机械时间表得到相同灌注，不受 ECG 形态影响。

初始压力、渐近压力、时间常数、通道延迟、波形支持及尾部重叠均独立保留。
1:1 房扑保留专用短射血时长与相应 RQ 换算，固定每搏系数用于该固定示例；
不宣称其在人工间歇后具有完整动态恢复。早搏沿用原有逐搏策略，不叠加第二次折减。
房颤、房扑及普通充盈策略互斥，构造时拒绝冲突。

计算按事件序号和局部相位索引，普通心律最多检查两个近期心房事件，房扑
最多四个；没有墙钟、随机源、从起点重放或累计积分。压力/光学源保持有限
历史、取消、幅度验证和精确检查点恢复。

CVP 的房室成分继续独立，房扑增加专用短促心房波。SpO₂ 目标、呼吸及 CO₂
不自动随充盈改变。模型未实现动态瓣膜、容积压力回路、收缩力与前后负荷反馈、
心室不同步、压力反射或炮击样 a 波；左右循环共用系数也是教学简化。

规格验证单调性、房室相位、真实 RR、机械中断/恢复、晚期索引、三通道一致、
压力线性折减、房颤/房扑差别及检查点恢复。黄金摘要有意变化范围见审阅表。
