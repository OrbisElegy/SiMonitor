# 潮式呼吸与呼出 CO₂ 的单向教学响应

潮式呼吸的既定深度序列同时驱动 Resp/CVP 深度、暂停事件和呼出 CO₂ 浓度。浓度通过单向储库响应深度变化；正常规则呼吸模式保持独立。

## 依据与作者选择

[Lorenzi-Filho 等的干预研究（1999）](https://pubmed.ncbi.nlm.nih.gov/10228116/)显示潮式呼吸中呼气末 CO₂ 与过度通气、后续暂停及循环延迟有关。[周期性呼吸实验模型研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC4189223/)亦观察到通气及呼气末 CO₂ 波动。这支持浓度随通气变化且存在相位差，不支持将胸阻抗波幅直接等同于 CO₂ 浓度。

本实现采用受既定深度序列驱动的单向储库：令 x 为高于吸入基线的浓度与参考浓度差之比，T 为源呼吸周期，d 为相对深度 permille，每槽使用

`x_next = (tau*x + T) / (tau + T*d/500)`。

恒定产生项与通气移除项形成滞后响应；tau=20s、参考深度500、11槽序列和后向Euler离散均为作者选择，未经临床标定，不是研究给出的参数。该模型不从配置的 Resp 计数幅度推断潮气量；反转或置零该信号幅度不会改变气体浓度。

计划构建时以有理数求精确周期稳态，随后将11槽增益按 ties-to-even 量化为 permille。不会从初始时刻逐呼吸重放，也不引入运行时浮点状态。初始即处于该周期轨道，并非疾病起病过程。

## 输出边界

- 呼气末及平台输入为参考值；仅缩放高于吸入基线的部分，基线不动。
- 深呼吸后浓度滞后下降；浅呼吸/暂停时储库回升。暂停槽无呼气事件，因此没有新的呼气末值；已触发尾波照常完成。
- 传输与展宽路径按原呼气事件的槽号使用相同增益，延迟不会错取下一个呼吸的深度。
- 耦合后的上界超过327mmHg则整次应用拒绝并保留原状态。固定绘图标尺可能无法覆盖全部有效浓度；标尺范围与动态缩放属于显示层，不改变源浓度。
- 规则呼吸不添加增益，保持已有数据。恢复和远期索引的工作量不随已运行时间增长。

该模型不包含完整化学感受器反馈、死腔/潮气量标定、PaCO₂/SpO₂或心输出量反馈，也不提供自动EtCO₂检测或数字读数链。其范围仅为潮式呼吸深度与呼出 CO₂ 的单向耦合，不涵盖其他呼吸模式、灌注或ECG模型的完整性验证。

## 验证

规格测试以独立浮点迭代核对1/3.75/10s周期稳态及量化，覆盖浓度滞后、重复周期、基线、暂停、延迟展宽、非法上限、数组所有权及大事件索引；生产计算保持整数/有理数。原生demo检查输出浓度、像素、wire恢复、应用拒绝及旧状态保持。数值与软件回归验证不等于生理模型临床验证。
