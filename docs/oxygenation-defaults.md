# 成人氧合基线与教师耗氧倍增器

参考集版本为 `AdultOxygenationDefaults@1`。桌面实时氧合入口现可根据年龄、
生理参考公式的性别系数、身高和体重计算基线；未指定的参数取参考中心或公式预测值，
不抽取随机个体偏移。逐项手工输入优先，患者资料修改只重算自动项。

这是一个明确指定来源的成人教学参考集，不是中国人群参考值，也不是经过联合验证的
正常患者分布。肺容量、Hb 和基础代谢分别来自不同研究；取各项中心值不能证明组合
具有临床代表性。当前没有儿童、妊娠、疾病、体位或肥胖专用的参考模型。

## 操作与状态边界

1. 设置 → 生命体征 → 指脉氧，启用双波长教学源和实时氧合模型。
2. 新建设置默认勾选“按患者资料计算基线（0 SD）”。填写年龄、参考性别、身高、
   体重，可分别勾选手工指定血容量、FRC、Hb 或基础耗氧量。自动值在界面显示至
   三位小数，实际求解使用完整 decimal 值。
3. 点击“应用并从头开始”创建该患者的初始氧储备，同时保存输入、覆盖选择、
   完整解析值、单位、来源和版本。调整基线会重新开始，不是运行中的失血或输血事件。
4. 平静基础状态的教师耗氧倍增器为 1。需要模拟额外耗能时，设置 1–4 倍并点击
   “更新通气／耗氧，保留当前氧储备”。该按钮同时更新 VT、VD、FiO₂、气道和倍增器，
   保留仿真时间、氧储备、原基线及光学测量窗口；未应用的患者资料草稿不会随之生效。

倍增器的 1–4 倍是本原型支持的编辑范围，不是对躁动、发热等状态的临床分级。
需求为“本次运行的基础耗氧量 × 倍增器”；供氧不足时实际耗氧可以低于需求，差额计入
未满足耗氧账本。它不自动改变心率、通气或基础参数。初始储氧按基础状态建立，再由
所选倍增器推动状态变化。运行时修改在下一个尚未开始的 8 ms 区间生效，旧样本不重算。

完整自动参考的年龄交集为 **20–80 岁**，还须符合体格和储库参数范围。
18–19 岁需手工 Hb；80 岁以上需手工 FRC；BMI 不在 18.5–<30 时需手工血容量。
不将年龄夹到边界，不静默外推或用旧常数补充缺失来源。整体成人入口为 18–90 岁、
140–210 cm、40–150 kg；血容量 2500–7500 mL、FRC 500–5000 mL、Hb 6–20 g/dL、
基础耗氧 0–500 mL(STPD)/min，还要通过完整组合的初始平衡检查。这些是原型边界，
不是正常值范围；极端身高对应的参考预测也可能超出当前储库支持范围。

旧偏好没有患者参考字段时，继续使用原先的固定研究基线及 1 倍耗氧；缺少整个氧合
字段时继续使用原来的固定目标模式。用户可勾选新基线并整体应用。取消患者默认值会
明确显示旧原型基线，不将其标为 0 SD。保存不包含运行中的氧储备或采样历史。

## 来源、公式与中心定义

### FRC：GLI 2021 的 LMS 中位数

[Hall 等原始论文](https://doi.org/10.1183/13993003.00289-2020)的 Table 3 及补充
查找表提供年龄、身高和性别系数。来源为欧洲裔健康不吸烟者，原参考覆盖 5–80 岁；
本实现仅使用成人部分。该范围和人群说明也见
[GLI 官方工具页](https://www.ersnet.org/science-and-research/ongoing-clinical-research-collaborations/the-global-lung-function-initiative/gli-tools/)。

LMS 的 z=0 等于 M，即中位数，不是把正常范围上下限取平均。年龄用岁，身高用 cm，
公式结果为 L(BTPS)，乘 1000 后输入储库：

```text
男性：M = exp(-13.4898 + 0.1111 ln(age) + 2.7634 ln(height) + Mspline(age))
女性：M = exp(-12.7674 + 0.1251 ln(age) + 2.6049 ln(height) + Mspline(age))
```

使用原始 XLSX 男、女 FRC 工作表中 18–80 岁、每 0.25 岁的完整精度 M-spline。
两节点之间线性插值，80 岁端点直接使用最后一项，不外推。仿真端以有界 decimal
log/exp 计算，不依赖平台浮点数学；Python math 实现提供独立数值对照。
FRC 是功能残气量，未用肺活量、TLC 或潮气量替代，也未额外添加未经验证的体位系数。

### Hb：NHANES III 年龄组均值

[Beutler 与 Waalen 2006](https://pmc.ncbi.nlm.nih.gov/articles/PMC1895695/) Table 2
的 NHANES III 列给出经过文中排除条件筛选的美国白人成年人均值；女性样本排除妊娠。
这里使用均值作为 0 SD，未使用贫血阈值、参考区间中点或同表 Scripps 列。

| 年龄（岁） | 男性 Hb（g/dL） | 女性 Hb（g/dL） |
| --- | --- | --- |
| 20–<30 | 15.51 | 13.57 |
| 30–<40 | 15.29 | 13.66 |
| 40–<50 | 15.20 | 13.58 |
| 50–<60 | 15.17 | 13.76 |
| 60–<70 | 14.94 | 13.66 |
| 70–<80 | 14.70 | 13.68 |
| ≥80 | 14.29 | 13.44 |

遵循来源年龄组，不跨组插值，不推算 18–19 岁。来源的人群限定保存在元数据中，
未引入隐藏的族群修正，也不能将本表解释为任意患者的实测 Hb。

### 基础耗氧：Schofield 基础代谢与 Weir 换算

[FAO/WHO/UNU 2004 Table 5.2](https://www.fao.org/4/y5686e/y5686e07.htm)列出
Schofield 的基础代谢预测公式。使用其 kcal/day 列，体重 W 用 kg：

| 本实现年龄分段 | 男性 BMR（kcal/day） | 女性 BMR（kcal/day） |
| --- | --- | --- |
| 18–<30 | 15.057 W + 692.2 | 14.818 W + 486.6 |
| 30–<60 | 11.472 W + 873.1 | 8.126 W + 845.6 |
| ≥60 | 11.711 W + 587.7 | 9.082 W + 658.5 |

取回归预测的零残差，不加活动系数。BMR 的参考条件比一般“安静坐着”严格，包含
清醒、休息及空腹等基础条件；FAO 同时讨论来源队列及跨人群适用性的局限。
这不是不依赖体重的同组实测 VO₂ 均值。

按简化 Weir 关系 `EE = 3.941 VO₂ + 1.106 VCO₂`，令 RQ = VCO₂/VO₂ = 0.8：

```text
基础 VO₂ [mL(STPD)/min] = BMR [kcal/day] × 1000 / (1440 × (3.941 + 1.106 × 0.8))
```

系数关系可见[原始间接测热研究](https://doi.org/10.1152/japplphysiol.01212.2003)，
气量使用 STPD 的说明见[间接测热验证研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC6358081/)。
这是忽略尿氮项的近似；RQ=0.8 与储库的既有假设一致，不是人口学推算结果。
教师倍增器在换算后的基础 VO₂ 上相乘，基础值保持不变。

### 血容量：Nadler 回归预测

[Nadler 等成人研究](https://pubmed.ncbi.nlm.nih.gov/21936146/)的估计使用身高 h（m）
和体重 W（kg）：

```text
男性 mL = 1000 × (0.3669 h³ + 0.03219 W + 0.6041)
女性 mL = 1000 × (0.3561 h³ + 0.03308 W + 0.1833)
```

它是性别和体格条件下的回归预测，不是年龄／性别组的 0 SD 均值。沿用原型的
BMI 18.5–<30 自动估算范围，其他体格需显式血容量；该限制是产品原型的保守范围，
不能引用为 Nadler 论文的适用边界。手工血容量仍须满足储库校验。

### 默认成人示例

35 岁、男性参考公式、175 cm、70 kg、全部自动时：

| 参数 | 解析结果（显示舍入） |
| --- | --- |
| 血容量 | 4823.755 mL |
| FRC | 3157.197 mL(BTPS) |
| Hb | 15.29 g/dL |
| BMR | 1676.14 kcal/day |
| 基础 VO₂ | 241.201 mL(STPD)/min |
| 2 倍耗氧需求 | 482.401 mL(STPD)/min |

动静脉分室比例、分流、参考每搏量、RQ、耗氧受限阈值及气量恢复时间仍是假定参数。
VT 和 VD 是教师设置的物理输入。这些量未被冒充为年龄／性别 0 SD 默认值。
SpO₂ 仍由红光／红外采样得到，无有效脉动时仍不可用；PLETH、RESP 的物理含义不变。

这些检查验证实现和数值行为，不是临床预测准确性验证。
