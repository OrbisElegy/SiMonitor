## 血容量与患者资料

需要给定血容量。血液储氧量等于血容量乘以氧含量，血容量也进入分室混合的时间尺度。
这一步支持两种来源：由成人资料估算，或直接输入场景血容量。使用预设患者时无需
每次重新填写资料；后续界面应显示参数来自“估算”“预设”还是“手工指定”。

成人估算采用 [Nadler 等，1962](https://pubmed.ncbi.nlm.nih.gov/21936146/) 的公式。
原论文书目信息已核对，系数与单位另由
[Chang 等，2017，Table 1](https://pmc.ncbi.nlm.nih.gov/articles/PMC5534181/) 核对。
身高 h 用 **m**，体重 w 用 **kg**，结果 V 用 **L**：

```text
男性系数：V = 0.3669 h³ + 0.03219 w + 0.6041
女性系数：V = 0.3561 h³ + 0.03308 w + 0.1833
```

| 输入 | 在当前原型中的用途 |
| --- | --- |
| 年龄 | 判断成人估算入口是否适用；不进入 Nadler 方程 |
| 性别系数 | 明确选择 Nadler 的男性／女性系数，不根据姓名推断 |
| 身高、体重 | 估算总血容量；cm 在入口换算为 m |
| 直接指定的血容量 | 覆盖估算入口，与四项资料输入互斥 |
| 动脉分配比例 | 独立的有效分室参数，不由 Nadler 计算 |

参考配置为 35 岁、男性系数、175 cm、70 kg，估算总量 **4.8237546875 L**。
年龄改为 80 岁而其余条件不变，公式结果不变。170 cm、70 kg 时，男性／女性系数
分别给出约 4.660／4.248 L；这些是公式输出，不是血容量实测值。

估算入口暂限年龄 18–90 岁、身高 140–210 cm、体重 40–150 kg、BMI 在 [18.5,30)。
这些是本项目限制实验范围的选择，**不是 Nadler 论文给出的已验证边界**。
儿童、孕期、肥胖及病理性血容量改变不在个体化声明内；直接指定总量也不会使
成人模型自动适用于这些人群。肥胖下简单固定 mL/kg 估计的局限可参见
[Lemmens 等，2006](https://pubmed.ncbi.nlm.nih.gov/16756741/)。

当前有效动脉／系统静脉分室按总量的 20%／80% 划分；这不是解剖血容量分布声明。
总血容量和分配比例分别做敏感性实验。仅由四项资料估算血容量，并没有个体化
FRC、耗氧、Hb、心排量、分流和疾病状态；当前数值原型仍逐项显式设置这些参数。

## 后续患者参数的默认规则

按暂定的产品规则，未来未单独输入的肺容量、Hb、耗氧量等生理基线参数，
使用**同性别、同年龄段参考模型的 0 SD（z=0）位置**，默认不随机抽取个体偏移。
这些高级参数不要求用户逐项填写；用户指定某一项时，只覆盖该项的自动默认。
实时 C# 入口现已实现首版成人参考集，来源、适用人群、公式及验证见
[成人氧合基线](../../interfaces/oxygenation/oxygenation-defaults.md)。本文的原始 Python 实验仍使用显式研究基准。

本文中 0 SD 统一解释为所选参考模型的中心位置。普通正态 z 分数对应均值；
采用 LMS 等偏态参考模型时，应由该模型求 z=0，不能一律当作算术均值，
也不能拿参考区间上下限的中点替代。比如
[GLI 静态肺容量参考模型](https://doi.org/10.1183/13993003.00289-2020)
使用性别、年龄、身高和 LMS 参数，其中 M 是中位数。
首版成人入口使用其**欧洲裔**参考 FRC 中心，未推广到所有人群。

| 参数 | 默认值解析要求 |
| --- | --- |
| 肺容量 | 本模型实际需要 FRC，不能用肺活量或 TLC 替代；取相应参考模型的 z=0，模型包含身高时使用已有患者身高 |
| Hb | 取适用性别、年龄组的中心值；不能将贫血诊断界限或参考范围下限当作默认 |
| 耗氧需求 | 取约定静息状态下的参考中心值；来源包含体重／体表面积等因素时用患者资料计算，并统一成 mL O₂(STPD)/min |
| 其他生理基线参数 | 逐项确认是否存在适用的参考模型；数值求解步长、气量恢复时间等作者参数不自动套用人口学 0 SD |

性别和年龄是默认分层的基础，不丢弃已知身高、体重等被参考公式使用的条件。
参考模型若支持连续年龄，直接计算该年龄的 z=0；若只提供年龄组，沿用来源的
分组边界，不擅自补出未有证据的年龄插值或组间标准差。

默认值解析应遵守以下行为：

- 用户明确输入优先；修改年龄、性别、身高或体重时，只重算仍处于自动模式的参数。
- 保存参数值、单位、自动／手工来源、参考模型版本和 z=0 选择，以便实验重现。
- 尚无适用参考数据时，明确标记为暂用场景基准或不支持，不把作者常数标成该人群 0 SD。
- 基线解析发生在创建或明确编辑患者时；缺氧、失血等场景过程不能因补默认值而被重置。
- 完整解析后重新核验模型适用范围与初始稳态；各项单独处于中心位置不自动保证组合有效。

现有 FRC=2.2 L、Hb=15 g/dL、耗氧=250 mL/min 仍是原型研究基准，
**不是默认患者的 0 SD**。这些值保留作旧实验回归；新入口按参考集解析患者基线，
基础耗氧由公式计算，教师倍增器单独控制额外需求，不改变已有实验曲线。

## 三个有效储库与单位

第一阶段把前期研究的扩展结构约简为：肺泡混合气体、动脉血、系统交换／静脉血。
肺毛细血管末端与肺泡瞬时平衡，组织耗氧合并到静脉分室；因此本版不能用于无流停搏。
支持的血流实验范围为 2.5–8 L/min，Q=0 会被拒绝。

肺气体保存 O₂、CO₂、惰性气体三个分量，两个血液分室分别保存氧量。
所有气体量与耗氧均以 mL(STPD) 计；血液容积用 mL，肺容积、VT、VD 用 mL(BTPS)。
假定海平面气压 760 mmHg、37°C、水蒸气压 47 mmHg：

```text
k = (273.15 / 310.15) × (713 / 760) ≈ 0.826238365
气体量(STPD) = 容积(BTPS) × k
肺泡氧分压 PAO₂ = 713 × 肺泡氧量 / 肺泡总气体量
```

固定标准温度和 pH 的解离曲线、Hb 结合氧与溶解氧形式沿用
[研究文档的静态关系及来源](oxygenation-model-research.md#从氧含量到饱和度)：

```text
S(P) = (P³ + 150P) / (P³ + 150P + 23400)
C(P) = [1.34 Hb S(P) + 0.0031 P] / 100
```

P 用 mmHg，Hb 用 g/dL，C 用 mL O₂(STPD)/mL 血液。反求 P 后得到 SaO₂。
数值求逆采用有界二分；内部按氧含量混合，不平均饱和度百分比。

设 Q 为 mL 血/s，f 为分流比例，Ca、Cv 为动／静脉氧含量，Ccap=C(PAO₂)。
Va、Vv 为相应固定血容量，OL、Oa、Ov 为储氧量：

```text
JL = Q(1-f)(Ccap-Cv)
JT = Q(Ca-Cv)
M  = M需求 × min(1, Cv/C低氧阈值)

dOL/dt = I氧 - E氧 - JL
dOa/dt = JL - JT
dOv/dt = JT - M
```

每个内部通量在边界两侧使用同一个有符号量，允许氧反向交换。
额外记录进入、离开、实际耗氧和未满足耗氧需求的积分账本；应保持：

```text
OL + Oa + Ov - 累计进入氧 + 累计离开氧 + 累计实际耗氧 = 常数
```

耗氧阈值取 Cv=2 mL/dL，低于时线性减小实际耗氧。这是防止无限消耗的作者闭合假设，
不代表已标定的细胞耗氧曲线；未满足需求的积分不能解释为器官损伤程度或死亡时限。
不通过截断负储量来掩盖数值问题，非法状态直接报错。

## 肺气体与呼吸的闭合假设

以 RQ×实际耗氧作为即时进入肺气体的 CO₂ 源。惰性气体没有血液交换项。
开放气道的混合气体洗出率 G 在吸气时段启用，每周期积分为 `max(VT-VD,0)×k`。
呼气时段 G=0；瞬时交换模型中吸入、呼出同时发生，这是有效洗出近似，
不是吸呼气的真实容积波形，也不是死腔气体逐段推进模型。

另设净肺气体摄取 U=JL−RQ×M，容积恢复项 R=(参考气量−当前气量)/τ：

```text
气道开放：I气 = G + max(0, U+R)，E气 = G + max(0, -U-R)
气道关闭：I气 = E气 = 0

d肺CO₂/dt = RQ×M - E气×肺CO₂分数
d肺惰性气体/dt = I气×(1-FiO₂) - E气×肺惰性气体分数
I氧 = I气×FiO₂，E氧 = E气×肺氧分数
```

气道关闭时等压储库可以收缩；开放时 τ=2 s 使气量恢复到参考 FRC。
气道压力、真实肺顺应性及重新开放动力学均未建模。
由于没有血液 CO₂ 缓冲和 Bohr 位移，**开放气道的无通气供氧以及长时间暂停结果
尤其不能用于定量临床预测**。开放气道实验当前只检验不同边界的收支行为。

以平均通气方程的解析解初始化，再推进完整呼吸周期，直到相邻周期五个储量的
最大差小于 1e-8 mL；最多 1024 周期，失败时拒绝初始化。
准备过程的代谢账本在实验开始前归零，气体与血氧储量保持连续。
预充氧实际推进供氧过程，不把饱和度直接赋值为 100%。

## 参考参数与实验安排

来源和作者假设分开保存在参数 JSON 中。成人量级取值依据与前期研究一致，
不把文献队列的范围当作本原型的临床验证范围。

| 参数 | 参考值 | 本轮单因素实验 |
| --- | --- | --- |
| FRC | 2.2 L(BTPS) | 1.1、3.3 L |
| VT／VD／RR | 450／150 mL，16 次/min | VT 250；VD 100、200 |
| FiO₂ | 0.21 | 0.15；预充氧及开放气道供氧 1.0 |
| 吸气占比 | 0.4 | 固定 |
| 心排量 | 5 L/min | 3、7 L/min |
| 总血容量 | Nadler 约 4.824 L | 3.5、6.5 L；170 cm、70 kg 两套性别系数 |
| 有效动脉分配比例 | 0.2 | 0.1、0.3 |
| Hb | 15 g/dL | 10、18 g/dL |
| 耗氧需求 | 250 mL(STPD)/min | 150、350 |
| 分流 | 0.02 | 0、0.1 |
| RQ | 0.8 | 固定 |
| 耗氧限制阈值／气量恢复时间 | 2 mL/dL／2 s | 1、4 mL/dL；0.5、5 s |

共 32 个情景。典型暂停协议为正常 30 s、气道关闭且零 VT 90 s、恢复通气 330 s。
低通气与低 FiO₂ 持续 180 s；反复暂停为三组 30 s 暂停加 30 s 恢复。
预充氧情景在记录前供 100% 氧 150 s，再记录 30 s 供氧基线，总计 180 s 后暂停。
1200 s 长暂停仅用于储量耗尽数值压力测试，不属于生理可信性声明。

## 首轮结果与解释

默认配置、Python 3.12、积分步长 50 ms、记录间隔 0.5 s，结果如下。
T90 为暂停开始后首次向下穿越模型 SaO₂ 90% 的线性插值时间，限于 90 s 的暂停窗。
它不包含指端传输、仪器平均窗口或采集延迟，不是监护 SpO₂ 报警时间。

| 暂停情景 | 初始 SaO₂ | T90（s） | 整段协议最低 SaO₂ |
| --- | --- | --- | --- |
| 参考 | 97.73% | 41.15 | 64.79% |
| FRC 1.1 L | 97.72% | 23.61 | 54.01% |
| FRC 3.3 L | 97.73% | 57.73 | 75.92% |
| 耗氧 150 mL/min | 98.59% | 89.74 | 89.87% |
| 耗氧 350 mL/min | 96.25% | 20.98 | 39.25% |
| 血容量 3.5 L | 97.73% | 38.68 | 58.70% |
| 血容量 6.5 L | 97.73% | 43.91 | 69.31% |
| Hb 10 g/dL | 97.58% | 39.17 | 51.74% |
| Hb 18 g/dL | 97.78% | 42.36 | 69.51% |

这些输出支持将储量、供氧和耗氧分开建模，尚不支持把某个 T90 固定为教学或临床默认值。
各情景都重新求初始周期稳态，因此参数改变也可能改变初始 SaO₂。
总血容量固定时，动脉比例从 0.1 改为 0.3，T90 约从 36.84 s 变为 44.78 s；
仅估算总血容量不能解决分室比例的不确定性。

低通气、低 FiO₂、反复暂停的最低 SaO₂ 分别约为 83.25%、92.04%、87.15%。
短暂恢复保留前次氧储量的影响，没有重置生理状态。
预充氧使初始储氧增加，暂停窗内未穿越 90%；JSON 的 `null` 和 CSV 空单元格表示
观察窗内未到达，不能解释为零秒或无限安全时间。所有情景的 T90／T85 均使用
记录时间 [30,120] s 这个窗口；低通气等更长协议的最低值则统计完整记录。

数值核验共 15 项通过：全部情景最大氧守恒残差约 9.24e-10 mL；关闭气道暂停 90 s
耗去 375 mL O₂，与实际耗氧积分相等；平均通气解析稳态无漂移，周期稳态量差低于
1e-7 mL。步长缩至 25／12.5 ms 后，参考暂停曲线最大 SaO₂ 差小于 9e-7 个百分点。
这些很小的数值误差不代表生理预测具有相同精度。

耗氧限制阈值在这组短暂停中没有改变曲线，因此不能用短暂停拟合该阈值。
FRC、耗氧、血容量、Hb 等实验是预先选定的单因素范围，不是人群置信区间，
也没有对全部参数组合做穷举验证。

## 重现方法与产物

在仓库根目录执行；核心模型、测试和 CSV/JSON 导出只使用 Python 标准库：

```sh
python3 -m unittest discover -s tools -p test_oxygenation_model.py -v
python3 tools/run_oxygenation_prototype.py
python3 tools/run_oxygenation_prototype.py --blood-volume-ml 6500 --output artifacts/oxygenation-explicit
python3 tools/run_oxygenation_prototype.py --age-years 35 --sex female --height-cm 170 --weight-kg 70 --output artifacts/oxygenation-profile
```

修改其他参数可通过 `--config` 指定 JSON。非法资料、无有效稳态、负储量或不收敛均报错。
配置参数的允许范围不保证任意组合都有可接受的有氧初始稳态。

绘图依赖可选的 Matplotlib，本轮使用 3.10.7；可安装到独立目录后运行，
无需更改应用或全局 Python 依赖：

```sh
python3 -m pip install --target artifacts/oxygenation-plot-deps 'matplotlib==3.10.7'
PYTHONPATH=artifacts/oxygenation-plot-deps MPLCONFIGDIR=artifacts/oxygenation-mpl python3 tools/run_oxygenation_prototype.py --plot
```

默认输出 `artifacts/oxygenation-prototype/`，该目录被 Git 忽略：

- `results.json`：完整配置、有效参数、每个情景、检查结果、步长、Python 版本和两个实现文件的 SHA-256。
- `summary.csv` 与各情景 CSV：SaO₂、PaO₂、SvO₂、肺泡 PO₂、气量、氧储量及收支账本。
- `oxygenation-overview.png`／`.svg`：曲线对照；`plot-environment.json`：绘图库版本，仅在 `--plot` 时生成。

17 项标准库回归检查覆盖公式单位、成人输入、手动覆盖、氧量平衡、反向交换、耗氧限制、
零耗氧、呼吸与控制边界、检查点恢复、非法输入、导入无副作用和 CLI 拒绝行为。
本轮还核对了两次独立运行的 34 个数值产物（32 个情景 CSV、汇总 CSV、结果 JSON），
逐字节一致，且结果中的源码哈希与当前文件一致。
数值推进在呼吸和控制边界处分步；同一环境的相同输入应可重现。
检查点必须保留绝对仿真时间，不能恢复时将呼吸相位重置。网格内任意细分可能改变
浮点舍入，本原型不承诺跨平台逐位一致，也不替代运行时确定性验收。
