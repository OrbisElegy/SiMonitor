# ECG 监护检测依据与能力边界

[文档导航](../../README.md) · [接口](../../interfaces/alarms/ecg-monitoring.md)

依据是用户指定的 Philips **Patient Information Center iX Release 4.4 Instructions for Use**，
文档号 4536 650 29231，2025 年第一版。
[原始说明书](https://www.documents.philips.com/assets/Instruction%20for%20Use/20250321/d80393498eb1407e8912b2a7015f378e.pdf?feed=ifu_docs_feed)。

这是中心监护系统说明书。其描述的多项分析实际由床旁监护仪／遥测设备完成；不同设备的
功能不完全相同。它适合确定监护事件的名称、证据和时间规则，不能据此还原专有算法。

## 从手册到本项目

| 手册位置（印刷页码） | 对本项目的用途 |
|---|---|
| 6-11～6-16；7-23～7-24 | 心率、停搏、间歇、室性与室上性事件的条件定义。 |
| 7-6～7-11 | 区分检测能力等级、报警链与通知行为；检测结果不直接等同于声音请求。 |
| 7-22；8-10 | 主导心搏模板学习、重新学习及在室性节律中误学模板的局限。 |
| 8-10～8-11 | 停搏、暂停、连续搏数、速率、PVC/min 和节律结束延迟的配置边界。 |
| 7-24～7-25 | 起搏脉冲与 QRS 必须分开检测；起搏模式下区分未夺获与未起搏。 |
| 7-26～7-28 | ST 测量位置、持续性要求和相邻导联条件；单导联结果不能冒充 STE。 |
| 7-28～7-31；8-18～8-19 | QT、QTc、基线变化、持续性要求与不可分析状态。 |

修改前，采集端已有 QRS/HR、信号有效性、心律不齐和保守的疑似房颤筛查；HR 越界报警已在
呈现层使用，十二导联窗口也已有手工测量。发生器中的心律名称、QTc 配置和波形模板本身
均不是检测结果。新增分析坚持从同一采集样本链路建立证据，复用原有原子发布、分包无关和
checkpoint 语义。

实现的事件规则和配置详见[接口](../../interfaces/alarms/ecg-monitoring.md)。其中形态匹配、
宽度与差异阈值、频率筛查、基线稳定性、T 终点和证据失效时间均是本项目自行制定的教学
近似，不是从说明书推导出的临床分类器。对 R-on-T 的检测还受原有 QRS 最短 200 ms 峰间距
约束；不能覆盖更短耦联。主导宽 QRS 会被学习成模板，因此在持续室速中直接开始学习仍可能
漏检，这与手册所提醒的学习前提一致。当前保留原有房颤的保守心房证据门槛与 RR 筛查，
不是声称复现厂商的逐搏 N 分类和全部 AF 判据。

手册 7-24 的 R-on-T 规则使用极短 RR，而本项目长 QT 室早模板的联律间期为 500 ms，
仅延长室早前一搏的 T 波。仅实现该 RR 规则会漏掉此模板中可见的重叠，直接使用此前测得
的普通 QT 也无效。因此增加了从紧邻前搏采集轮廓筛查未结束 T 波的教学扩展，并保留
原有确认规则，详见接口。窗口排除室早 QRS，检查基线、T 幅度、连续性及末段趋势；
相同联律但正常 T 波的室早作为反例。该外推不能确定被 QRS 遮挡的真实 T 终点，不应表述为
复现厂商算法或临床验证的 R-on-T 分类器。

手册 7-16、7-22 与 8-10 说明了初始 15 搏学习、显式重新学习及异常节律中学习的局限，
没有公开本项目可照搬的自动恢复判据。本项目对初始模板不匹配和 RR 参考停滞增加了
连续稳定窄 QRS 确认后更新参考的机制，见接口中的“测量失效后的自动恢复”。这一机制
独立于 ST/QT 是否暂时可测；不因 T 波缺失而周期性重置检测器，也不把仍持续的室速或
快速室上速当成新的正常参考。

房早差异传导不能仅凭宽 QRS 判作室早。[ACC 的房早伴 RBBB 病例](https://www.acc.org/education-and-meetings/patient-case-quizzes/2020/01/06/08/20/jan2020-ecg-of-the-month)
以提前且形态改变的 P 波和后续差异传导复合波区分房早与室早。当前单导联教学实现增加了
独立 P 样波与保留的初始 QRS 轮廓的联合筛查；具体阈值是项目启发式规则，不来自厂家公开
分类器，也不能替代多导联鉴别。验证以真实采集的房早差异传导模板为正例，并改变其 P 波、
在真正室早前添加 P 样波作为反例，避免依赖模板名称或仅凭一个前置波形推断起源。

## 可用证据限制

- 室性与室上性输出是候选分类；单导联无法可靠区分全部差异传导、束支阻滞、宽 QRS
  心动过速或运动伪迹。稳定宽 QRS 不自动生成 VT；低幅／不匹配形态可为未知。
- 室颤筛查要求持续的低频、平滑活动和缺少已确认 QRS。它不把 Uncountable 一概判为室颤；
  停搏筛查也要求静默波形，不能把未知噪声当成平线。未标记的复杂噪声仍可能干扰教学筛查。
- 起搏故障的规则已提供，但内置 illustration 采集器没有可信脉冲旁路输入；因此默认实时
  会话不宣称具备起搏故障检测。未来采集适配器必须提供契约要求的实际检测证据。
- 单导联 ST/QT 是自动教学读数。实现没有厂商的代表搏动平均、多导联选择或完整 U 波排除；
  复杂 ST/T/U、房扑和融合波仍可能使估计偏离手工测量，必须保留质量与未知状态。
- 多导联回退、ST Multi/STE、ST index 及硬件电极状态需要新增采集与联合分析，当前未实现。
  报警声音、优先链、锁存和提醒属于皮肤／通知策略。默认皮肤依据 7-10 的分支关系提供
  检测项优先抑制；未把厂家的跨链超时、全局单项播报或完整 HR 优先链复制到检测器。

这些边界属于接口能力说明；不应藏在皮肤的视觉样式或以“正常”填充缺失结果。

## 起搏事件与抑制选择

PIC iX IFU 7-23～7-25 定义有／无起搏脉冲时的长 RR 事件，提醒尖峰及高大 P 波可能掩盖
停搏；7-7～7-11 描述固定通知超时及优先链；7-25 与 QT 章节说明心室起搏的复极分析限制。
另参照 [Philips ST/AR 应用说明](https://www.documents.philips.com/doclib/enc/fetch/2000/4504/577242/577243/577247/582636/582637/PM_-_Arrhythmia_Monitoring_ST_AR_Algorithm_AN_4522_991_65051_(ENG).pdf)
的脉冲剔除与起搏心搏分类描述。两者都不能作为从 250 Hz 显示尖峰恢复真实设备脉冲的依据。

本项目采用显式仿真旁路，与真实采集分开；只输入脉冲时刻、腔室及预期起搏间期，夺获仍需
采样 QRS。8 ms 显示脉冲剔除、250 ms QRS 等待、启动期参考间期、低幅 P 波容忍门槛和
30 s 同项重复通知抑制均为作者选择，非厂商参数。30 s 用于减少四周期故障示意反复发声，
警报文字仍保留；持续停搏会由更高等级警报接替。当前复用逐项通知计时，不实现厂商的
完整跨报警超时链。心室起搏时暂停 RR 驱动的房颤／不齐推断是本项目证据不足的处理，
并非宣称所有起搏患者都不可能有房颤。AAI 保留自身心室分析，危急 ECG 及血流动力学警报
不整体关闭。具体生效边界见[接口](../../interfaces/alarms/ecg-monitoring.md#起搏旁路证据)。
