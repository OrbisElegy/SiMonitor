# ECG 监护检测依据与能力边界

[文档导航](../../README.md) · [接口](../../interfaces/alarms/ecg-monitoring.md)

依据是用户指定的 Philips **Patient Information Center iX Release 4.4 Instructions for Use**，
文档号 4536 650 29231，2025 年第一版。
[原始说明书](https://www.documents.philips.com/assets/Instruction%20for%20Use/20250321/d80393498eb1407e8912b2a7015f378e.pdf?feed=ifu_docs_feed)。

这是中心监护系统说明书。其描述的多项分析实际由床旁监护仪／遥测设备完成；不同设备的
功能不完全相同。它适合确定监护事件的名称、证据和时间规则，不能据此还原专有算法。

## 从手册到本项目

| 手册位置（印刷页码） | 对本项目的用途 |
|---|---|
| 6-11～6-16；7-23～7-24 | 心率、停搏、间歇、室性与室上性事件的条件定义。 |
| 7-6～7-11 | 区分检测能力等级、报警链与通知行为；检测结果不直接等同于声音请求。 |
| 7-22；8-10 | 主导心搏模板学习、重新学习及在室性节律中误学模板的局限。 |
| 8-10～8-11 | 停搏、暂停、连续搏数、速率、PVC/min 和节律结束延迟的配置边界。 |
| 7-24～7-25 | 起搏脉冲与 QRS 必须分开检测；起搏模式下区分未夺获与未起搏。 |
| 7-26～7-28 | ST 测量位置、持续性要求和相邻导联条件；单导联结果不能冒充 STE。 |
| 7-28～7-31；8-18～8-19 | QT、QTc、基线变化、持续性要求与不可分析状态。 |

修改前，采集端已有 QRS/HR、信号有效性、心律不齐和保守的疑似房颤筛查；HR 越界报警已在
呈现层使用，十二导联窗口也已有手工测量。发生器中的心律名称、QTc 配置和波形模板本身
均不是检测结果。新增分析坚持从同一采集样本链路建立证据，复用原有原子发布、分包无关和
checkpoint 语义。

实现的事件规则和配置详见[接口](../../interfaces/alarms/ecg-monitoring.md)。其中形态匹配、
宽度与差异阈值、频率筛查、基线稳定性、T 终点和证据失效时间均是本项目自行制定的教学
近似，不是从说明书推导出的临床分类器。对 R-on-T 的检测还受原有 QRS 最短 200 ms 峰间距
约束；不能覆盖更短耦联。主导宽 QRS 会被学习成模板，因此在持续室速中直接开始学习仍可能
漏检，这与手册所提醒的学习前提一致。当前保留原有房颤的保守心房证据门槛与 RR 筛查，
不是声称复现厂商的逐搏 N 分类和全部 AF 判据。

## 可用证据限制

- 室性与室上性输出是候选分类；单导联无法可靠区分全部差异传导、束支阻滞、宽 QRS
  心动过速或运动伪迹。稳定宽 QRS 不自动生成 VT；低幅／不匹配形态可为未知。
- 室颤筛查要求持续的低频、平滑活动和缺少已确认 QRS。它不把 Uncountable 一概判为室颤；
  停搏筛查也要求静默波形，不能把未知噪声当成平线。未标记的复杂噪声仍可能干扰教学筛查。
- 起搏故障的规则已提供，但内置 illustration 采集器没有可信脉冲旁路输入；因此默认实时
  会话不宣称具备起搏故障检测。未来采集适配器必须提供契约要求的实际检测证据。
- 单导联 ST/QT 是自动教学读数。实现没有厂商的代表搏动平均、多导联选择或完整 U 波排除；
  复杂 ST/T/U、房扑和融合波仍可能使估计偏离手工测量，必须保留质量与未知状态。
- 多导联回退、ST Multi/STE、ST index 及硬件电极状态需要新增采集与联合分析，当前未实现。
  报警声音、优先链、锁存和提醒属于皮肤／通知策略，不属于本次检测器事件实现。

这些边界属于接口能力说明；不应藏在皮肤的视觉样式或以“正常”填充缺失结果。
