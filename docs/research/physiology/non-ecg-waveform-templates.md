# 压力、PLETH、EtCO₂ 与 RESP 模板依据

调研日期：2026-10-17。本文区分临床上报告的形态、项目选择的教学示意和通道间的联动边界。
模板表示某一种可见信号，不是疾病分类器；也不按形态名称自动改变氧合、循环或治疗状态。

## 术语与形态选择

“射血”的过度衰减／窒息解释为 **ABP 测量系统过度阻尼**（overdamping），
不是生理性停止射血。阻尼可使压力上升变慢、峰形变钝、脉压变小和重搏切迹不清。
本项目只改变 ABP 测量波形，保留实际机械事件、PLETH、PA 和循环输送。
这与现有“无有效射血”模板具有不同含义。
依据：[AACN，有创血流动力学监测的动态响应评估，Procedure 59](https://www.aacn.org/docs/Photos/Procedure-59-4ihnnti3.pdf)。

PLETH 低灌注表示局部脉动分量减小，不等于血氧饱和度下降。
运动干扰表示外加的运动伪差，不把伪差峰当作真实机械射血。
实际设备在运动和低灌注下的测量能力不同；不能从屏幕形态独自决定 SpO₂ 数值。
依据：[Masimo Rad-57 手册，PI 与信号质量](https://techdocs.masimo.com/globalassets/techdocs/pdf/lab-9205a.pdf)、
[Gehring 等，运动与低灌注对血氧测量影响的志愿者实验](https://www.masimo.com/siteassets/us/documents/pdf/clinical-evidence/sphb/gehring-the-effects-of-motion-artifact-and-low-perfusion-on-the-performance-of-a-new-generation-of-pulse-oximeters-in-volunteers-undergoing-hypoxemia-jan-2002.pdf)。

以下 EtCO₂ 名称对应随时间变化的呼出 CO₂ 分压轨迹；纵轴使用 mmHg，
不是呼气流量或潮气量。EtCO₂ 数值仍由采集波形的测量层得出。

| 请求或译名 | 模板含义与选取的形态 | RESP 处理 |
| --- | --- | --- |
| 食管插管 | 最初数次小波逐渐衰减，随后无持续呼出 CO₂；也可能从一开始就无波 | 不自动抹去胸廓活动 |
| 右主支气管插管 | 双相呼气平台示意；实际也可能呈近正常波形 | 无通用特异形态，沿用已有模板 |
| 自发通气 | 圆钝、短平台的自发通气示意；并非所有自主呼吸都呈此形态 | 规则 RESP；深度与吸呼比可独立设置 |
| 间歇性机械通气 | 间歇指令通气（IMV）：强制呼吸与较小的自主呼吸相间 | 新增大小呼吸相间的 RESP |
| 阻塞模式 | II 期上升变慢、III 期斜升的“鲨鱼鳍”示意 | 可用既有吸呼比表达呼气延长 |
| 肺气肿 | 选择少见的 III 期反向斜率作为区别性示意；不是所有肺气肿的典型表现 | 不新增病名专属 RESP |
| 缓和松弛剂 | 肌松消退（箭毒切迹，curare cleft）：平台中出现下凹，表示机械通气中叠加的自主吸气努力 | 新增呼气期额外吸气努力示意 |
| 重新呼吸 | 再呼吸／重复吸入：吸入基线未回到零 | 保留 RESP |
| 饱和苏打石灰 | CO₂ 吸收剂耗竭（钠石灰失效）：再呼吸的一种原因 | 保留 RESP，不虚构独有形态 |
| 心脏震动 | 心源性振荡：气体波形出现与心搏相关的小波纹 | 不强制增加 RESP 伪差；现有心源伪差参数可独立使用 |
| 机械气道阻塞 | 部分机械性气道梗阻的呼气受限示意；完全梗阻可能无呼出 CO₂ | 不由 CO₂ 形态推断胸廓努力是否消失 |
| 辫子 | 猪尾样（pigtail）：呼气末上翘；可见于小气道闭合，也可能由采样管漏气造成 | 保留 RESP |

总体形态参考：[Bhavani Shankar Kodali，Interpret your capnogram](https://www.capnography.com/interpret-your-capnogram/)。
该作者维护的教材同时列出相似外形的多种原因，因此模板不建立“一个波形必然对应一种疾病”的关系。
右主支气管插管的双相平台和肺气肿的反向平台，另见
[胸科麻醉中的 CO₂ 波形](https://www.capnography.com/capnography-during-thoracic-anesthesia-sp-449728275/)
和[右支气管插管病例报告](https://pubmed.ncbi.nlm.nih.gov/2511783/)。
关于箭毒切迹，[膈肌活动与肌松程度的原始研究](https://pubmed.ncbi.nlm.nih.gov/7902740/)
支持将其用于说明呼吸努力，但不支持从切迹定量推断神经肌肉阻滞程度。
心源性振荡参考作者记录的[低频控制通气波形](https://www.capnography.com/ripple-effect/)。
猪尾样与小气道闭合的联系参考
[Kumar 等的婴儿病例报告](https://pmc.ncbi.nlm.nih.gov/articles/PMC2943704/)；
采样管原因见[双相与漏气 CO₂ 波形](https://www.capnography.com/dual-waveform-capnogram/)。
病例形态不外推为所有年龄或病因的必然表现。

## RESP 的联动边界

RESP 在此是相对胸阻抗／胸廓活动示意，不是气流计。
这一测量边界依据 [AARC 呼吸监测指南](https://www.aarc.org/wp-content/uploads/2014/08/12.05.1336.pdf)。
CO₂ 无波不意味着胸廓没有运动；反之，有胸廓运动也不能证明有效肺泡通气。
模板因此分开选择：仅 IMV 和额外吸气努力增加独立 RESP 外形。
不为再呼吸、吸收剂耗竭、猪尾样、食管插管或右主支气管插管重复建立普通 RESP。

气体与胸廓模板共用呼吸时间轴；选用相应模板时，IMV 的呼吸序号及箭毒切迹的努力位置保持对应。
CO₂ 管路传输延迟作用于气体读数，因此开启延迟后屏幕上的切迹可以晚于胸廓努力。
同一个形态并不证明肌松药浓度、阻塞程度或实际潮气量。

## 实现与参数证据

形态采样点、局部幅度、深浅循环、阻尼窗口与演示周期都是项目作者选择，
不是从教材图片描点得到的患者数据或经标定的器械响应。
没有复制第三方插图，也不以这些教学数值代表正常范围。
默认 CO₂、ABP、PA 与 CVP 的形态由项目自制曲线生成；异常模板仍通过显式选择启用。

CO₂ 与压力曲线在源头按作者选取的关键点生成有界的保形三次 Hermite 曲线，
再采样为 Q32 LUT。CO₂ 的斜率按死腔、上升、平台及吸气下降各阶段的实际时长计算，
避免在不等速的相位映射处引入额外折角。局部极值及平段的切线受限，
保留基线、切迹和终末值，不用全局平滑抹去这些特征。
算法原则参考 [SciPy 的 PCHIP 官方说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.PchipInterpolator.html)：
保留数据的单调性并限制过冲，通过局部斜率构造一阶连续曲线；二阶导数不要求连续。
项目使用独立的确定性计算与 Q32 量化实现，不引入 SciPy 运行依赖。

这次迁移替换非 ECG 通道的形态种子，沿用既有心搏／呼吸事件时间轴、压力 RC 储库、
传播延迟、测量与状态恢复链路。CVP 的 a、v 波及房扑心房分量使用新的平滑曲线；
c 波、x／y 下降支和呼吸分量保留既有项目自制 smoothstep 表，呼吸相位映射也保持不变。
PLETH 沿用既有项目自制形态，ECG 生成器不属于这次迁移范围。
采集、测量、模板预览和实时显示使用同一套源曲线，显示端的插点不承担修正源形态的职责。

ABP 阻尼在已有压力轨迹上做有界因果平滑，保留恒定压力和物理射血源。
PLETH 低灌注缩小脉动，运动干扰使用由仿真时间决定的有界伪差。
运行中切换时，脉动增益与运动伪差权重用 1 秒的 smoothstep 包络过渡，
避免在上升支截断采集波形；该时长是界面演示的工程选择，不代表灌注变化的生理时间常数。
过渡作用于采集样本，随后由同一 PLETH 调制生成光学双波长信号；不修改饱和度目标。
运动示意通过现有质量标记阻止污染样本被报告为可信 SpO₂／PR；这是项目的保守测量策略，
不声称所有商业设备都会丢失读数。

CO₂ 形态由呼气触发的定点波段组成，保留死腔、呼气、下一次吸气和传输延迟的时序。
食管插管衰减序列有结束条件，不能在模板循环后重新产生有效波形。
心源性振荡关联实际心室机械事件，不按每次呼吸硬编码固定波纹数。
运行中更换节律时，保留的旧呼气尾段只使用切换前的心搏事件；新节律的小波纹
自下一次呼气开始更新。
恢复、分块推进及模板切换应使用同样的求值路径，避免显示、保存和实时输出各自生成一套波形。
事件波段的状态保存实际 `TableQ32`，旧快照恢复时继续使用原表。
压力储库的形态模型默认版本更新为 `VascularPressureMorphologyRatio@3`，
保留 `@2` 的形态求值路径供旧 checkpoint 恢复，避免恢复时将旧状态静默解释为新曲线。

## EtCO₂ 数值检出

异常模板需要由实际采集样本识别呼吸，不能将模板名或目标数值直接写成测量结果。
抬高的吸气基线应以相对幅度识别呼吸；低幅心源性振荡不能计为独立呼吸。
反向平台则需要区分较早峰值与吸气下降之前的终末值。
参考 [Masimo 红外光谱与 CO₂ 测量白皮书](https://www.masimo.com/siteassets/us/documents/pdf/plm-14382a-whitepaper-masimo-infrared-spectrometry-global.pdf)：
其公开说明包括自适应呼吸门限、伪差排除及向呼气末倾斜的数值权重；
本项目只采用上述原则，检测门限和末段估计是独立工程实现，不复制其专有算法。
恒定高基线没有完整的吸呼周期，仍不能产生呼吸次数或新的呼气末读数。
