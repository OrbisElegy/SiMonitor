# SVT 充盈限制与血压修正

200 bpm 室上速原本沿用 75 bpm 参考射血强度，每 300 ms 输入 240 ms、
RQ=300 mmHg；仅 RC 部分稳态平均压就可达 250 mmHg。问题在每搏输入，
不应通过限制显示量程或削顶血压处理。

当前 `SvtPerfusionIllustration@3` 使用[逐搏充盈模型](cardiac-filling-perfusion.md)。
保留 240 ms 有效不可充盈时段、200 ms 充盈常数，并按实际房室机械相位
计算。本例房室同时收缩，没有正常先房后室的助泵贡献，每搏系数为 235‰；
此前只计算充盈时间的版本为 313‰。公共 `StrokeVolumePermille(RR)` 辅助函数
保留为仅比较充盈时间的参考曲线，产品使用完整逐搏策略。

[Sganzerla 等的 SVT 研究](https://pubmed.ncbi.nlm.nih.gov/2702964/)表明，
相似心率下房室时序仍可改变血流动力学。这支持计入相位，不验证本项目数值。
240 ms 不是从 QT 推算的真实瓣膜时间，也没有完整负荷、收缩力或压力反射模型。

同一系数应用于原始压力输入和光学幅度，压力整形仅折减一次，保留脉搏。
RC 回流、初值、渐近压力、原射血长度、波形尾部及有限历史保持独立。
中断期间不射血，恢复一搏按长间歇充盈，随后回到实际短 RR。

默认稳态 ABP 原参考为 264.08–295.74 mmHg，当前为 69.71–77.15 mmHg，
连续 12 秒均值 74.33 mmHg。这是教学参数的工程结果，不代表室上速必然低压。
规格验证输入受限、原始轮廓的线性比例、尾部重叠、无射血回流和一天后稳定性；
桌面检查覆盖三个 SVT 变体的实测平均压、收缩压与缓存波形。
